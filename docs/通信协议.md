## 一、帧格式

```
┌────────────┬──────────────┬────────┬───────┬──────────┬─────────────┐
│ 帧头 4B     │ 数据长度 4B   │ flags  │ cmd   │ body nB  │ CRC16 2B    │
│ AA CA AC BB│ 小端序        │ 1B     │ 1B    │ n 字节   │ 小端序      │
└────────────┴──────────────┴────────┴───────┴──────────┴─────────────┘
```

* **数据长度** = `flags(1) + cmd(1) + body(n) + CRC(2)`，小端序（4 字节）。
* **CRC16** = `CRC16_IBM(flags + cmd + body)`，小端序。
* 整帧长度 = `12 + n` 字节（n = body 长度）。

### CRC16_IBM

多项式 `0xA001`（反射写法）、初值 `0x0000`、不异或输出 —— 也就是标准 **CRC-16/ARC**：

```c
uint16_t CRC16_IBM(const uint8_t *data, uint16_t len) {
    uint16_t crc = 0x0000;
    for (uint16_t i = 0; i < len; i++) {
        crc ^= data[i];
        for (uint8_t b = 0; b < 8; b++)
            crc = (crc & 1) ? (uint16_t)((crc >> 1) ^ 0xA001) : (uint16_t)(crc >> 1);
    }
    return crc;
}
```

标准校验值：`CRC16_IBM("123456789") == 0xBB3D`（自检里会验这一条）。

## 二、命令表

| cmd | 含义 | body | 方向 |
| :--- | :--- | :--- | :--- |
| `0x01` | 上报颜色目标 | 颜色(1B) + X(2B) + Y(2B) + W(2B) + H(2B) | MaixCAM → STM32 |
| `0x02` | 上报形状目标 | 形状(1B) + X(2B) + Y(2B) + W(2B) + H(2B) | MaixCAM → STM32 |
| `0x10` | 设为颜色模式 | 无 | STM32 → MaixCAM |
| `0x11` | 设为形状模式 | 无 | STM32 → MaixCAM |
| `0x12` | 请求识别一次 | 无 | STM32 → MaixCAM |
| `0x00` | 空帧（没找到目标） | 无 | MaixCAM → STM32 |

body 里所有多字节字段都是**小端序**。

| flags | 值 | 含义 |
| :--- | :--- | :--- |
| 请求 | `0x01` | STM32 → MaixCAM |
| 上报 | `0x21` | MaixCAM → STM32 |

| 编号 | 颜色 | 编号 | 形状 |
| :--- | :--- | :--- | :--- |
| 1 | 红 | 1 | 圆柱形 |
| 2 | 绿 | 2 | 圆锥形 |
| 3 | 蓝 | 3 | 腰鼓形 |

## 四、STM32 端实现要点

### 4.1 接收 USART2（MaixCAM）：DMA + 空闲中断

```
USART2 RX ──DMA1_Stream5_Ch4(循环, 256B)──> s_dma_buf
     │                                          │
     ├─ 空闲中断 (IDLE)  ────────┐              │
     └─ DMA 半满/全满中断 ───────┤              ▼
                                 └──> 算新到字节范围 ──> 环形缓冲 (1024B)
                                                              │
                          主循环 MaixLink_Process() ◄──────────┘
                                 │
                                 ▼
                     逐字节状态机 Protocol_PushByte()
                                 │
                    ┌────────────┴────────────┐
                 CRC OK                    CRC FAIL
                    │                          │
                    ▼                          ▼
          Vision_OnFrame() → g_vision   g_maix_crc_err++，丢帧
                    │                    （状态机 300ms 超时后重试）
                    ▼
             g_vision_ready = 1
```

逐字节状态机：

```
PARSE_WAIT_HEAD1 → 等 0xAA
PARSE_WAIT_HEAD2 → 等 0xCA
PARSE_WAIT_HEAD3 → 等 0xAC
PARSE_WAIT_HEAD4 → 等 0xBB
PARSE_RECV_LEN   → 收 4 字节长度（小端）
PARSE_RECV_DATA  → 收 flags + cmd + body
PARSE_RECV_CRC   → 收 2 字节 CRC（小端）→ 校验
```

帧头任意位置错位都会自动重新同步（自检第 5 项专门验这个）。

### 4.2 接收 USART1（GM65）：逐字节中断

每收到 1 字节进中断 → 遇到 `\r` 或 `\n` 认为一行结束 → 主循环解析三位数字。
解析规则：取字符串里的数字字符，必须是**恰好 3 位且都在 1~3**，否则整行丢弃
（超时 3 s 后自动用占位值 `112` 继续跑，不会卡住）。

### 4.3 发送

`Maix_SendModeColor()` / `Maix_SendModeShape()` / `Maix_SendReqDetect()`
→ 组帧 → `HAL_UART_Transmit` 一次性发出（≤ 18 字节，115200 下 < 2 ms）。

### 4.4 有效范围判断（中心点）

```
640 × 320，中心 (320,160)，X: 160~480，Y: 80~240

cx = x + w/2 ;  cy = y + h/2
160 ≤ cx ≤ 480  且  80 ≤ cy ≤ 240   →  在范围内
```

### 4.5 重试逻辑

| 情况 | 动作 |
| :--- | :--- |
| CRC 校验失败 | 原地发 `0x12` |
| cmd 和当前状态不一致 | 原地发 `0x12` |
| 300 ms 没收到数据 | 原地发 `0x12` |
| 收到空帧 `0x00` | 原地发 `0x12` |
| 颜色/形状编号不匹配 | 原地发 `0x12` |
| 坐标不在有效范围 | 原地发 `0x12` |

* 所有异常都**原地重试，不调整位置**（视觉对准由机械臂固定位保证）。
* S3 / S6 / S9 各自独立计数，**每个环节最多 3 次**（= 1 次首发 + 2 次重试）。
* 3 次都失败 → 跳过当前任务，直接进入下一状态（`S3 → S5`、`S6 → S8`、`S9 → S11`）。

## 五、MaixCAM 端实现要点

**完全被动**：不主动拍图、不主动识别、不主动上报。

```
上电 → 初始化(摄像头/串口) → 等命令
   ├── 0x10 → 模式 = 颜色
   ├── 0x11 → 模式 = 形状
   └── 0x12 → 拍一帧 → 按当前模式识别一次 → 上报一帧 → 回等待
```

* 只上报**编号 + 原始坐标**，不做匹配判断、不做范围判断（那是 STM32 的事）。
* 找到就报 `0x01`/`0x02`，没找到就发空帧 `0x00`。
* 模式设置一次就记住，直到下次切换。
* 阈值（颜色 LAB、白色灰度、形状判别像素差）**现场必须重标**，见 `maixcam/main.py` 顶部。

## 六、完整时序

```
STM32                                          MaixCAM
  │  0x10 设为颜色模式                            │
  │ ────────────────────────────────────────────> │ 模式 = 颜色
  │  机械臂移到识别位, 蓝灯常亮 500ms               │
  │  全灭 200ms (等画面稳定)                       │
  │  0x12 请求识别一次                             │
  │ ────────────────────────────────────────────> │ 拍一帧
  │                                               │ find_blobs 识别颜色
  │ <──────────────────────────────────────────── │ 0x01 上报 (编号+坐标)
  │  绿灯慢闪期间收到 → CRC → cmd → 匹配 → 范围     │
  │  通过 → 存 g_target → S4                       │
  │                                               │
  │  (S6 保持颜色模式, 不再发 0x10, 只发 0x12)      │
  │  0x11 设为形状模式                             │
  │ ────────────────────────────────────────────> │ 模式 = 形状
  │  0x12 请求识别一次                             │
  │ ────────────────────────────────────────────> │ 拍一帧
  │                                               │ 灰度+二值化+宽度剖面
  │ <──────────────────────────────────────────── │ 0x02 上报
```
